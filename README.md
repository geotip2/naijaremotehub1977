# 🇳🇬 Naija Remote Hub

Find verified remote jobs, internships & gigs for Nigerians.

Live site: **https://tehub.netlify.app**

## What is this?

Naija Remote Hub helps Nigerians find real remote work without scams.
Job seekers can browse jobs, save jobs, and apply. Employers can post jobs.

## Features

- Browse verified remote jobs
- User login with Firebase Auth
- Save jobs & Dashboard
- Premium membership with Paystack
- Admin panel to manage jobs & users
- Mobile-friendly design

## Tech Used

- HTML, CSS, JavaScript
- Firebase Auth + Firestore
- Paystack Payments
- Netlify Hosting + Netlify Functions

## How to Run Locally

1. Clone the repo
2. Open `index.html` in your browser
3. Or run with Live Server in VS Code

## Project Structure

- `index.html` - Homepage
- `netlify/functions/` - Paystack webhook & backend functions
- `assets/` - Images, CSS, JS
